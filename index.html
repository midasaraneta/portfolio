Research & Publications

Capstone Project | IEEE

Controlled Environment for Spinach Cultured Plant with Health Analysis using Machine Learning

This study developed a controlled environment system for monitoring spinach health and growth in real time using mobile technology, environmental sensors, image processing, and supervised machine learning. The system collects data on humidity, temperature, and soil conditions, while spinach health is analyzed through image processing using classifiers to distinguish healthy and unhealthy plants. All data are monitored through the Spinach Monitoring Application (SPIMON) and stored in the cloud. Results showed that spinach grows best in a controlled environment.
